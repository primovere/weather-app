# Weather App

A simple weather application built with vanilla JavaScript to practice state-driven UI architecture and asynchronous data flow.

## Features

- Search weather by city name
- Display current temperature and weather conditions

## Tech Stack

- JavaScript
- HTML
- CSS
- Fetch API

## Key Concepts Practiced

- Centralized state management (`status`, `data`, `error`)
- Declarative UI rendering based on application state
- Asynchronous API handling with async/await
- Separation of data logic and UI rendering

## What I learned

- How to design UI based on state instead of manual DOM updates
- How to build predictable UI flows around asynchronous data
- How frontend frameworks like React approach rendering logic (simplified version)

## Future Improvements

- Add weather forecast (multi-day view)
- Handle race conditions for multiple fast requests
- Improve UI/UX design and responsiveness
